Codex has a Cycle reasoning effort command that changes the current thread live, but it ships with no keyboard shortcut. Bind one in Codex → Settings → Keyboard Shortcuts (search "reasoning"), then enter the same combo below.
Combos use "ctrl", "shift", "alt", "super" + a key, e.g. ctrl+alt+r. On a plain keypad the press cycles Light → … → Ultra. On a Stream Deck +, bind Increase/Decrease reasoning effort in Codex too and set them above.
